## 📌 Project Overview

**Mini Projects** is a curated collection of frontend web experiments, practical UI widgets, and foundational JavaScript exercises. 

This repository serves as a testing ground for mastering core JavaScript concepts, DOM manipulation, responsive layouts, and small-scale interactive web apps.

## 📂 Included Projects & Modules

| Module / Project | Description | Primary Concepts |
| :--- | :--- | :--- |
| 📝 **To-Do Application** (`todo/`) | Interactive task management interface for adding, completing, and managing daily tasks. | DOM Manipulation, Local State, Event Listeners |
| 🧮 **Calculator** (`calculator/`) | Keypad-based arithmetic calculator supporting fundamental math operations. | Math logic, CSS Grid, Event Handling |
| 🌸 **Perfume Product Page** (`perfume/`) | Responsive e-commerce product landing page with modern layout typography. | Flexbox, Responsive Design, Product Presentation |
| 🧪 **JS Fundamentals** (`array.html`, `object.html`, `function1.html`, `variable.html`) | Code exercises and practical examples demonstrating core JavaScript data structures and methods. | ES6 Syntax, Array methods, Object manipulation, Functions |

---

## 🛠️ Technologies Used

- **HTML5**: Semantic document structuring and accessible layouts.
- **CSS3**: Responsive styling, Flexbox, Grid systems, and custom UI components.
- **JavaScript (ES6+)**: DOM manipulation, array and object methods, functions, and event-driven architecture.

## ⚙️ How to Run Locally

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/akhileshyadav865722/Mini_Projects.git
   cd Mini_Projects
   ```
2. **Open Any Module in Browser:**
   - Open any specific project folder (e.g. `todo/index.html`, `perfume/index.html`) or exercise file directly in your browser or with VS Code **Live Server**.
